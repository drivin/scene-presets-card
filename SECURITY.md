# Security policy

## Supported version

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature on the repository's **Security** tab when it is available. If it is not enabled, open an issue asking the maintainer for a private contact channel, without including vulnerability details. Do not publish a vulnerability before a fix is available.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an initial response within 14 days.
