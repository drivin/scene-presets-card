# Contributing

Thank you for helping improve Scene Presets Card.

## Development setup

Use Node.js 22 or newer:

```sh
npm ci
npm test
npm run build
```

For browser tests, install Chromium once and run both browser suites:

```sh
npx playwright install --with-deps chromium
npm run test:browser
npm run test:cache
```

Edit files in `src/`. Do not edit `scene-presets-card.js` directly; it is generated by `npm run build` and must be committed whenever its source or version changes.

Before opening a pull request, make sure the tests pass, rebuild the bundle, and update `CHANGELOG.md` for user-visible changes. Keep pull requests focused and describe how the change was verified.

Translations must keep the same keys and named placeholders in every language. See [docs/LOCALIZATION.md](docs/LOCALIZATION.md) for details.
